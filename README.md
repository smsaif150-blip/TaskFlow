
# TaskFlow

A modern Android task management application built with Kotlin and Jetpack Compose.

## About
TaskFlow is a task management app designed to help users organize their daily activities, manage priorities, and track productivity.

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Room Database
- Dagger Hilt
- Kotlin Coroutines
- StateFlow
- Navigation Compose

## Features
- [ ] Create tasks
- [ ] Edit and delete tasks
- [ ] Mark tasks as completed
- [ ] Task priorities
- [ ] Task categories
- [ ] Search and filter tasks
- [ ] Due dates and reminders
- [ ] Dark mode
